MotorAI dashboard-theme project website

1. Extract the ZIP.
2. Open index.html in a browser.
3. To publish publicly, upload index.html and style.css to a GitHub repository and enable GitHub Pages.

Notes:
- The visual dashboard panel on the homepage is illustrative, not live telemetry.
- Current listed hardware: Raspberry Pi Pico W, DS18B20 temperature sensor and MPU6050 motion/vibration sensor.
- Relay is intentionally not included.
- Update the project details and readings to match your final tested setup.
