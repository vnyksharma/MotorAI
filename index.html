03 / WORKFLOW

How MotorAI works.

The system follows a simple data pipeline, from physical sensing to readable information.

01

Sense

DS18B20 measures temperature while MPU6050 captures acceleration data related to vibration.

02

Process

Raspberry Pi Pico W reads the sensors and prepares the measurements for transmission.

03

Visualize

The backend receives and stores readings, which are presented through a monitoring dashboard.

04

Analyze

AI-based analysis explores historical temperature behaviour and provides experimental trend forecasts.

04 / PROJECT GOALS

Built around awareness.

↗ Monitor motor temperature continuously.

↗ Observe vibration patterns and changes.

↗ Maintain historical sensor readings.

↗ Explore early-warning insights using data analysis.

↗ Present key information through a clear dashboard.

05 / WHAT'S NEXT

Moving towards
predictive maintenance.

Future development can include testing under different motor loads, collecting a larger real-motor dataset, improving anomaly detection and validating model performance under practical operating conditions.
